# مكتبة الحديث | Hadith Library

[English](README.md) · [O‘zbekcha](README.uz.md)

**كتب الحديث وشروحها — اقرأ وابحث بلا إنترنت، وانسخ الاقتباس مع مصدره.**

- **سهل الاستعمال:** المكتبة ← اختر كتابًا ← ثبّت *الكتاب وحده* أو *الكتاب مع الشروح التي تختارها* ← اقرأ أو ابحث ← افتح شرح هذا الحديث ← انسخ الاقتباس مع مصدره. لا حساب، ولا بايثون، ولا مفتاح API، ولا ذكاء اصطناعي.
- **بلا إنترنت على ويندوز وماك وآيفون وأندرويد:** تطبيق ويب قابل للتثبيت (PWA). كل كتاب وكل شرح حزمة مستقلة تُحفظ على جهازك.
- **ربط في الاتجاهين:** إذا ثُبّت الكتاب وشرحه معًا، فتح الحديثُ مواضعَ شرحه، وأعاد الشرحُ إلى حديثه — للطبعة والإصدار المتوافقين فقط.
- **صراحة في القيود:** كل نتيجة تُظهر حالتها (متحقَّق · مقيَّد · متعارض · غير موجود · لم يُراجع) وتغطيتها وترخيصها. التطابق في البحث ليس تحقيقًا مؤكدًا لهوية الحديث.
- **الواجهة بالعربية والإنجليزية** (والأوزبكية). النص العربي للمصدر يُعرض دائمًا من اليمين إلى اليسار، ولا يُترجم آليًا.

- 🗂️ ¹ **شجرة الكتب والأبواب** كما في الطبعة، ثابتة في مكانها أثناء القراءة، تُظهر موضعك.
- 🔗 ¹ **إسناد مقروء:** لكل راوٍ رقم موضعه ¹²³، وبلمسة واحدة **الأسماء فقط**: فلان ← فلان ← النبي ﷺ — دون «حدثنا / عن».
- 👤 ¹ **صفحة الراوي:** كم حديثًا ورد فيه اسمه، وفي أي موضع من الإسناد، وفي أي كتاب وباب.
- ✨ **كلام النبي ﷺ مميَّز** داخل النص (عرضًا فقط؛ نص المصدر لا يتغيّر).

¹ طبقة الأبواب والرواة (من بيانات الشاملة و AuthenticIlm، منشورة بإذن صاحب المصدر) تُثبَّت تلقائيًا مع الكتاب — [التنزيلات](https://github.com/Nbeast19/vositalar/releases/tag/hadis-manba-qatlamlar-v1).

## للمستخدم المتقدم (اختياري)

أداة سطر أوامر للحاسوب (بايثون 3.10+) بنفس نموذج البيانات: بحث نصي SQLite، واستيراد آمن للحزم، والرجوع إلى إصدار سابق، وتدقيق مجلدات المصادر، وخدمة محلية على `127.0.0.1`، و**خادم MCP** لعملاء الذكاء الاصطناعي:

```sh
pip install ".[mcp]"
hadis-manba doctor
hadis-manba install book.hmz
hadis-manba search "انما الاعمال بالنيات"
hadis-manba mcp
```
